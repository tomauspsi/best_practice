# Attività programmate nell'app Claude: stato al 1 novembre 2026 (v2)

v2 sostituisce v1 (27 ottobre), che copriva anche Claude Code, GitHub Actions, Managed Agents e l'API. La storia sta nei commit. Le pagine di support.claude.com arrivano dallo strumento come riassunto: qui sono parafrasi, senza virgolette, salvo i nomi di menu e pulsanti. Le voci del changelog di Cowork sono riassunte in italiano, con il numero di versione; le poche citazioni in inglese restano sotto le 15 parole.

## Risposta breve
- Nell'app un'attività programmata gira nel cloud, anche con il PC spento; resta sul PC solo se usa file locali, browser o computer del PC.
- Si crea chiedendolo in chat o da «Scheduled» nella barra laterale; frequenze: ogni ora, giorno, settimana, giorni feriali o a mano.
- Ogni run è una sessione nuova: il prompt deve bastare da solo.
- Vede connettori, plugin, skill, file dell'account, Istruzioni del profilo e, nel Project, il contesto del Project. Nessuna pagina descrive una scelta dei connettori per singola attività.
- Conta sui limiti del piano come il resto dell'uso; i crediti d'uso entrano solo oltre un limite e se attivi.
- Per controllarla: «Run now», run passate nella pagina «Scheduled», notifica «Scheduled task failed», notifiche sul telefono a fine lavoro.

## Regole operative
1. Spiega dove gira: nel cloud, anche a PC addormentato o app chiusa; le attività che richiedono file o app locali girano solo sul PC; su Pro, Max e Ultra quelle create prima del 6 ottobre che giravano sul PC restano lì. File locali, browser e computer use richiedono Claude Desktop aperto. [Verificato] · T1 · <https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork>; <https://support.claude.com/en/articles/15520349-use-claude-cowork-on-web-desktop-and-mobile>
2. Crea l'attività in chat (descrivi compito e frequenza, rispondi alle domande, rivedi nome, orario e istruzioni, «Schedule») oppure da «Scheduled» > «New task» > «Create with Claude» o «Set up manually» (modulo «Create scheduled task»: nome, prompt, «Approval mode», frequenza, modello e cartella facoltativi, «Save»). `/schedule` non è più nel menu dal 22 ottobre: scriverlo compila una richiesta. [Verificato] · T1 · <https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork>; <https://claude.com/docs/cowork/changelog> (v3.6556.1)
3. Gestisci tutto dalla pagina «Scheduled»: clic sull'attività per cambiare istruzioni o frequenza, pausa e ripresa, «Run now», eliminazione; nella barra laterale il menu ⋮ dell'attività ha «Mark as unread» per l'ultima run. La pagina d'aiuto non dà i nomi esatti dei comandi di pausa ed eliminazione. [Verificato] · T1 · <https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork>; <https://claude.com/docs/cowork/changelog> (v1.26832.0)
4. Offri le frequenze documentate: hourly, daily, weekly, weekdays, manually. Fuso, una tantum, intervallo minimo e numero massimo non sono documentati per l'app. [Verificato] le frequenze e l'assenza · T1 · <https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork>
5. Scrivi un prompt autosufficiente che nomini dove salvare il risultato: ogni run è una sessione Cowork a sé, con contesto nuovo. [Verificato] · T1 · <https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork>; <https://academy.claude.com/tutorials/delegating-and-scheduling-tasks-in-claude-cowork>
6. Conta su ciò che l'attività vede: connettori e plugin configurati in Cowork, skill, file salvati nell'account, cartella facoltativa; le Istruzioni del profilo valgono in ogni attività programmata; un'attività creata da una conversazione del Project gira ogni volta con il contesto del Project. [Verificato] · T1 · <https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork>; <https://academy.claude.com/courses/introduction-to-claude-cowork/giving-cowork-context>; <https://support.claude.com/en/articles/14116274-organize-your-tasks-with-projects-in-claude-cowork>
7. Limita i connettori dai permessi, non solo dal prompt: nessuna pagina descrive una scelta dei connettori per singola attività; per ogni connettore si impostano «Always allow», «Needs approval» o «Blocked» in Customize > Connectors > connettore > «Tool permissions». [Verificato] i permessi · [Inferenza] che l'attività veda tutti i connettori configurati · T1 · <https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities>
8. Scegli la modalità di approvazione con criterio: «Manually approve» per file sensibili, account, siti o strumenti nuovi e azioni difficili da annullare; «Automatically approve» controlla ogni azione e blocca quelle pericolose; con «Skip all approvals» nulla controlla le azioni. Dal 1 ottobre le attività create da Claude usano «Automatically approve» dove l'organizzazione lo permette. La cancellazione definitiva di file chiede sempre il permesso. [Verificato] · T1 · <https://support.claude.com/en/articles/13364135-use-claude-cowork-safely>; <https://claude.com/docs/cowork/changelog> (v2.19675.0)
9. Non contare su approvazioni date a distanza: uno strumento marcato «ask» mostra la richiesta e aspetta, e una run più recente della stessa attività ritira la richiesta rimasta senza risposta; gli strumenti MCP che richiedono una persona chiedono solo nella scheda dell'app e l'attività prosegue senza quelle chiamate; fuori da «Auto» e «Skip all approvals» il web fetch richiede un URL nominato nelle istruzioni o trovato cercando. [Verificato] · T1 · <https://claude.com/docs/cowork/changelog> (v2.31226.0, v3.6556.1, v4.29.0)
10. Rivedi il risultato dopo ogni run: la pagina «Scheduled» mostra run future e passate, ogni run si rivede come una sessione; se l'attività non parte arriva «Scheduled task failed». Nessuna pagina dell'app dice cosa significhi una run «riuscita». [Verificato] · T1 · <https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork>; <https://support.claude.com/en/articles/13364135-use-claude-cowork-safely>; <https://claude.com/docs/cowork/changelog> (v2.31226.0, v2.110.0)
11. Di' quali notifiche arrivano: sul telefono quando Claude finisce un compito o ha bisogno di input; nessuna pagina dice dove si impostano né parla di e-mail. [Verificato] · T1 · <https://support.claude.com/en/articles/15520349-use-claude-cowork-on-web-desktop-and-mobile>
12. Metti in conto il consumo: tutto l'uso conta sui limiti del piano; claude.ai, Claude Code e Claude Desktop condividono lo stesso limite; i lavori con più passi consumano di più. I crediti d'uso si usano solo dopo un limite incluso esaurito e se attivati in Settings > Usage; la pagina non nomina né Cowork né le attività programmate. [Verificato] · T1 · <https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude>; <https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work>; <https://support.claude.com/en/articles/12429409-extra-usage-for-paid-claude-plans>
13. Programma solo compiti a basso rischio: niente file sensibili, messaggi a nome dell'utente, acquisti o azioni irreversibili; metti in pausa o elimina le attività che non servono; l'utente resta responsabile di ciò che Claude fa per suo conto. [Verificato] · T1 · <https://support.claude.com/en/articles/13364135-use-claude-cowork-safely>
14. Riduci il rischio di prompt injection togliendo una delle due condizioni: Claude legge contenuti fuori dal perimetro fidato e insieme può compiere azioni dannose. L'isolamento del cloud protegge PC e rete, non limita ciò che Claude fa con gli accessi concessi. [Verificato] · T1 · <https://support.claude.com/en/articles/13364135-use-claude-cowork-safely>
15. Per un risultato scritto scegli un posto raggiungibile da dove l'attività gira: una cartella del PC obbliga a girare in locale (Desktop aperto, PC sveglio); nel cloud restano i file dell'account, i documenti tramite connettore e la risposta della run. [Verificato] le condizioni · [Inferenza] la scelta · T1 · <https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork>; <https://support.claude.com/en/articles/15520349-use-claude-cowork-on-web-desktop-and-mobile>

## Stato dell'arte

### A. Dove si crea e dove gira
- Creazione in chat, nell'esperienza unificata: si descrive il compito e la frequenza, Claude fa domande, propone nome, orario e istruzioni, si conferma con «Schedule». Esempio ufficiale: ogni giorno feriale alle 8 riassumere i nuovi messaggi dei canali Slack. [Verificato] T1 · help 13854387; [help 16761823](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude)
- Creazione dalla barra laterale: «Scheduled» > «New task» in alto a destra > «Create with Claude» (domande, anche a scelta multipla, poi «Schedule») o «Set up manually» (modulo «Create scheduled task»: Task name, Prompt, Approval mode, Frequency, Model facoltativo, Folder facoltativo; «Save»). [Verificato] T1 · help 13854387
- `/schedule`: help 13345190 dice ancora di scriverlo in un'attività; il changelog del 22 ottobre lo toglie dal menu e lo trasforma in una richiesta come il pulsante Schedule. [Verificato] T1 · [help 13345190](https://support.claude.com/en/articles/13345190-get-started-with-cowork); changelog v3.6556.1
- Dove gira: nel cloud, con nessun dispositivo acceso; le attività già sul PC restano lì, le nuove vanno nel cloud; file locali, connettori locali, browser e computer use richiedono Claude Desktop aperto; ad app chiusa la sessione continua ma non raggiunge i file locali. [Verificato] T1 · help 13854387; help 15520349; [help 13364135](https://support.claude.com/en/articles/13364135-use-claude-cowork-safely)
- Superfici: le attività programmate risultano disponibili su desktop, web e mobile; piani: Pro, Max, Ultra, Team, Enterprise; su Team ed Enterprise l'accesso a Cowork passa da un interruttore dell'admin. [Verificato] T1 · help 15520349; help 13854387
- Project: ogni Project ha una voce «Scheduled tasks» per attività proprie del Project; si creano da una conversazione dentro il Project e girano ogni volta con il contesto del Project (Istruzioni, cartelle o link, memoria). Le pagine non dicono cosa succede alle attività quando il Project viene archiviato o spostato. [Verificato] T1 · [help 14116274](https://support.claude.com/en/articles/14116274-organize-your-tasks-with-projects-in-claude-cowork); [Academy, giving Cowork context](https://academy.claude.com/courses/introduction-to-claude-cowork/giving-cowork-context)
- Frequenze: hourly, daily, weekly, weekdays, manually. Il changelog cita anche orari come «the 1st and every Monday» e «every N days/months» (correzioni del 20 e 25 agosto), quindi l'app accetta orari più fini di quelli del modulo. [Verificato] T1 · help 13854387; changelog v1.34493.0, v1.37937.0 · [Inferenza] sulla portata

### B. Cosa vede una run e come chiede
- Accesso: connettori e plugin configurati in Cowork, skill, file salvati nell'account, cartella di lavoro facoltativa. Dal 22 ottobre Claude trova plugin e skill anche nelle attività non aperte a schermo. [Verificato] T1 · help 13854387; changelog v3.6556.1
- Istruzioni del profilo (Settings, «Global instructions» o «Instructions for Claude»): Claude le usa in ogni sessione, ogni chat e ogni attività programmata. [Verificato] T1 · Academy, giving Cowork context
- Memoria: Claude usa la memoria delle chat nelle attività su cui lavora; la memoria delle attività rimaste solo sul PC resta con quelle. Nessuna pagina dice in modo esplicito che una run programmata legga o scriva la memoria. Dettagli: `D:\Workspace\best_practice\4_memoria\rapporto_memoria.md`, sezione «D. Cartella locale e attività programmate». [Verificato] T1 · help 16761823 · [Inferenza] sulle run programmate
- Connettori: per una conversazione si accendono da «+» > «Connectors»; i permessi per strumento stanno in Customize > Connectors > connettore > «Tool permissions»; la pagina li presenta tra i poteri degli owner di Team ed Enterprise. Nessuna pagina descrive i connettori per singola attività. [Verificato] T1 · [help 11176164](https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities)
- Modalità: nella casella di testo «Manual», «Auto» (predefinita su Pro, Max, Ultra e Team) e «Skip»; in Auto passano gli strumenti di sola lettura e per scrittura e cancellazione decide Claude, con un controllo di sicurezza; se i blocchi si ripetono torna a chiedere. Nei nomi della pagina sulla sicurezza: «Manually approve», «Automatically approve», «Skip all approvals». [Verificato] T1 · help 13345190; help 13364135
- Approvazioni senza nessuno davanti: 8 ottobre, uno strumento «ask» mostra la richiesta e aspetta, e una run più nuova ritira la richiesta senza risposta della precedente; corretta anche una richiesta di accesso a una cartella già concessa che lasciava le run in attesa. 22 ottobre, gli strumenti MCP che richiedono una persona chiedono solo nella scheda dell'app e le attività vanno avanti senza quelle chiamate. 27 ottobre, il web fetch nelle attività fuori Auto e Skip richiede un URL nominato nelle istruzioni o trovato da una ricerca. [Verificato] T1 · changelog v2.31226.0, v3.6556.1, v4.29.0
- Una pagina Academy dice che Cowork chiede l'approvazione prima di ogni azione importante (inviare un'e-mail, pubblicare un messaggio, cambiare un file fuori dalla cartella). [Verificato] T1 · [Academy, choosing between Cowork or chat](https://academy.claude.com/tutorials/choosing-between-claude-cowork-or-chat)

### C. Costi e limiti
- Tutto l'uso conta sui limiti del piano; i compiti agentici che cercano, eseguono codice o creano file consumano in genere più di una domanda; controllo in Settings > Usage. [Verificato] T1 · help 16761823; help 13345190
- Limite di sessione di cinque ore (dal primo messaggio; assente sugli account Ultra verificati) e limiti settimanali; claude.ai, Claude Code e Claude Desktop contano sullo stesso limite; la pagina non nomina Cowork né le attività programmate. [Verificato] T1 · [help 11647753](https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work)
- Crediti d'uso: si usano solo dopo aver esaurito un limite incluso (cinque ore, settimanale, settimanale di Fable su Max e Ultra), vanno attivati e prepagati (Settings > Usage > «Usage credits» > «Enable», «Adjust limit», «Add funds»), costano a tariffe API e si fatturano a parte. La pagina copre conversazioni, Claude Code, Research e Project; per Cowork dice solo che i crediti API mensili non valgono lì; non nomina attività programmate né sessioni nel cloud. La pagina oggi si intitola «Manage usage credits for paid Claude plans». [Verificato] T1 · [help 12429409](https://support.claude.com/en/articles/12429409-extra-usage-for-paid-claude-plans)
- Cosa succede a un'attività programmata che arriva al limite senza crediti attivi: nessuna pagina dell'app lo dice. [Verificato] l'assenza
- Osservazioni dell'utente, che riguardano Claude Code e non le attività dell'app. Notte 03 (attività cloud programmata) e notte 04 (chat locale): piano su, crediti fermi. 1 novembre, sessione cloud di Claude Code avviata a mano: scende il saldo dei crediti cloud regalati da Anthropic all'account, separato dal limite del piano. Nessuna pagina letta descrive crediti dedicati al cloud: help 11647753 e help 12429409, riletti il 1-nov, parlano solo di limite del piano e di crediti d'uso oltre il limite. [Obsoleto/Conflitto] · [Inferenza] su una sola sessione

### D. Esiti e notifiche
- La pagina «Scheduled» mostra run future e passate; ogni run è una sessione Cowork e il risultato si rivede come in ogni altra attività; le run passate si vedono dalla pagina «Scheduled» su ogni superficie. [Verificato] T1 · help 13854387; help 13364135
- «Scheduled task failed»: compare quando un'attività non riesce a partire, anche se il suo ambiente non si avvia (correzioni del 15 settembre e dell'8 ottobre). [Verificato] T1 · changelog v2.110.0, v2.31226.0
- Telefono: notifica quando Claude finisce un compito o ha bisogno di input; un'attività avviata dal desktop compare nell'app mobile, dove si seguono i progressi e si risponde alle domande. [Verificato] T1 · help 15520349; help 16761823
- Impostazioni delle notifiche ed e-mail: nessuna prova trovata. Pagine controllate: help 13854387, 13345190, 16761823, 15520349, 13947068, release notes dell'app; una voce delle release notes del 29 settembre 2025 diceva di accendere le notifiche per avvisi su permessi e compiti finiti, senza percorso. [Verificato] l'assenza
- Affidabilità (changelog): run ripetute dopo 5, 15 e 30 minuti se non raggiungono il modello (4 settembre); corrette run doppie al risveglio del PC (11 giugno) e attività locali non modificabili dopo la prima run (13 ottobre). [Verificato] T1 · changelog v1.46388.1, v1.12603.1, v2.37337.1

### E. Scrivere un documento o un file
- Un'attività può leggere e scrivere nella cartella di lavoro scelta; il tutorial Academy salva il riepilogo come documento in una cartella nominata e consiglia di indicare nel prompt dove salvare. [Verificato] T1 · help 13854387; [Academy, delegating and scheduling](https://academy.claude.com/tutorials/delegating-and-scheduling-tasks-in-claude-cowork)
- Un'attività che richiede file locali gira solo sul PC; nel cloud raggiunge i file del PC solo con Claude Desktop aperto e solo nelle cartelle collegate. [Verificato] T1 · help 13854387; help 13364135
- Documenti Google tramite connettore, permessi di scrittura e approvazioni: `D:\Workspace\best_practice\4_memoria\rapporto_memoria.md`, sezione «C. Scrivere un documento-memoria». Nessuna pagina descrive un'attività programmata che aggiorni un documento Google; in «Automatically approve» le scritture le decide Claude con il controllo di sicurezza. [Inferenza] fondata su help 13345190 e help 10166901
- Un riepilogo che serva da memoria al Project: possibile solo come documento esterno (Google o file) che l'utente poi mette o sincronizza nella knowledge; nessuna pagina dice che un'attività scriva nella knowledge o nella memoria del Project. [Inferenza]

### F. Lavoro in parallelo
- Si possono far girare più attività insieme; le domande rapide restano rapide; i compiti lunghi continuano nel cloud a portatile chiuso. [Verificato] T1 · help 16761823
- Per compiti complessi Claude divide il lavoro e può coordinare più sottoagenti contemporaneamente. [Verificato] T1 · help 13345190
- Se un compito ha parti indipendenti, Cowork le esegue insieme (esempi: cinque aziende da studiare, tutti i contratti di una cartella). [Verificato] T1 · Academy, choosing between Cowork or chat
- Consumo: ogni passo usa token e i compiti a più passi consumano di più; nessuna pagina quantifica il consumo di attività parallele o sottoagenti. [Verificato] l'assenza · [Inferenza] che il parallelo consumi più in fretta
- Dispatch (agente che lancia più attività figlie) è in beta limitata, chiuso ai nuovi utenti, e gira sul PC acceso: fuori dal perimetro di questa guida. [Verificato] T1 · [help 13947068](https://support.claude.com/en/articles/13947068-assign-tasks-from-anywhere-in-claude-cowork); [docs Dispatch](https://claude.com/docs/cowork/guide/dispatch)
